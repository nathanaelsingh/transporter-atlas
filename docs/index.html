Evidence discipline

1. Genetic or cellular association

GWAS, CRISPR perturbation, localization, metabolomics: generates hypotheses.

2. Direct activity in a controlled system

Flux, electrophysiology, or translocation: supports a transporter/channel claim.

3. Mechanistic confirmation

Substrates, stoichiometry, coupling, state structures, mutagenesis and rescue.

How this stays current

Every week after deployment

A scheduled GitHub Action queries Europe PMC for each protein and rebuilds the public site with a dated publication snapshot.

Every new paper enters a queue

A matching title is not treated as evidence. First-seen dates and reviewer flags help prioritize reading.

Scientific classification requires review

Evidence strength, direct activity, compartment and mechanism change only after a source-supported manual update.

Keep the research recoverable

The complete source code, target dataset, updater and tests are bundled. Personal notes can be exported and imported.

Data policy

The site does not upload research notes or review decisions. It requests only public literature metadata when you choose a live query, and it can be used offline. Automatic refresh requires GitHub hosting or another scheduled runner.

Do not publish unpublished sequences, sensitive lab information, or personal notes to a public repository. GitHub Pages itself is public even when supported by a private repository.
